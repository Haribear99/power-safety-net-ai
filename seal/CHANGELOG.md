  - 지시 원문은 `seal/S9_corpus_brief.md`에 있다.

- **사전등록 집계**
  - 9.5(보낸 글 1차 위반 0)는 구조상 보장되는 확인 항목이라 적중 집계에서 뺐다.
  - 그래서 N1은 4/6, '예비·사전 분석 뒤 확인'은 35/37이다(틀린 6개는 그대로).
  - `out/n1_sealed.json`에는 7개가 모두 그대로 있다.
  - `n1-analyze.ts`는 이제 Python 재검사를 직접 실행한다. 손으로 넣던 인자를 없앴고, 결과는 같다.
- **치명: 119 이송 예정 시각이 지난 경우**
  - 이송 예정 시각이 지나면 고정 문안과 AI 글이 '아직 정해지지 않았다'로 거짓 안내했다.
  - '이송 예정 시각이 지나 담당자가 확인 중'으로 고쳤다(facts.ts, rules.ts, check.ts).
- **중대 수정**
  - 시계가 흐르면 AI 결과가 0.5초 안에 버려졌다. 이제는 사실 묶음이 바뀔 때만 버린다.
  - 산소통 가구가 재신고하면 배터리 끝이 늘었다. 이제는 직전 끝에서 산소통 몫을 뺀 값을 상한으로 둔다.
  - 심사용 코드 요청은 judge 풀을 쓴다.
  - 2차 검사 v8은 상황(정전 중/복구됨/정전 전), 금지 지시(negated), 기관 약속(staffPromises), 쉼터·구급대 이름, 이송 시각 지남을 본다.
  - 1차 검사는 정전 중 안내에 '복구·다시 들어옴'을 금지하고 '정전'을 필수로 한다. 뒤집기 낱말(보다·이상·넘게·늦게·전에·안에)도 더했다.
  - '수정'으로 고른 119(시각 없음)는 늦음과 먼저 소진을 보수적으로 경고한다.
  - 평시 안내에 원안의 '대체장소'('갈 곳을 담당자와 미리 정해 두세요')와 '절전 가능 여부'(담당 의료진·대여업체 확인, 설정은 혼자 바꾸지 않음)를 고정 문장으로 붙였다.
  - 기술요약을 3줄 안으로 줄였다.
- **경미 수정**
  - 기기 이름 대조의 조건이 반대로 되어 있던 것을 고쳤다(UNKNOWN이면 구체 기기명 금지).
  - 검사 단계에서 예산이 막히면 '한도 도달'로 표시한다.

  - 가구 화면에 '보호자 있음' 선택을 넣었다.
  - 보호자용 꼬리말을 쉽게 고쳤다.
  - /lab에 '수치는 v6, 지금 쓰는 검사는 측정 안 됨'을 적었다.
