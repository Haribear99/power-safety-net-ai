# E5 사전등록 — AI 라벨 판독의 기여와 기록 기반 표적 사전 배치 (2026-10-18)

> **왜 E5인가.** 레드팀 2라운드(10/18)가 두 가지를 지적했다.
> 1. 헤드라인 모의는 기종 판독이 늘 맞다고 가정해 AI의 몫이 0이다(AI 구현 항목 약점).
> 2. 끝 훅 「등록 기록으로 사전 배치 대상을 고른다」는 모의에서 시험하지 않았다(P7은 무작위 보급).
>
> E5는 이 둘을 같은 시나리오 안에서 공통 난수로 잰다.

## 0. 설계

- **정전 길이.** E4와 같은 실측 분포 `APT_EMP`(기후에너지환경부 382건)를 쓴다. 18축 LHS 추첨(척도 배수 1)이고 마스터는 `E5`다.
- **봉인 실행.** 시드 5,000,001~5,002,000, 2,000추첨, 1회만 실행한다. 예비 실행은 시드 9,501~9,700(마스터 `E5-dev`)으로 하고, 버그 확인용이다. 예비 실행을 본 뒤 예측을 더하지 않는다.
- **갈래(미확인 기종 비율만 다름, 나머지 진실은 같음).**
  - AI: 봉인 C1 시험셋에서 DB 등록 기종 자동 확정에 실패한 비율 24/90 = 0.266667만큼 미확인 → 수동검토.
  - NOAI: 라벨 판독 없음. 모든 기종이 미확인이다.
  - PERF: 판독이 늘 맞음(상한). 미확인 0이다.
- **변형.** `AI@KR_BASELINE`, `AI@RULE`, `NOAI@RULE`, `PERF@RULE`, `AI@RULE+P7`, `AI@RULE+P7T`
- **P7T(표적 사전 배치).** P7과 같은 보급량 round(0.6 × covMult × 등록 가구 수)를 배터리 하한 끝이 이른 등록 가구부터 준다. 순위는 평시 수동검토가 끝난 화면(PERF 갈래 계획자 화면)으로 매긴다. 고장·에너지·효율은 P7과 같다.
- **지표.**
  - 공백 가구·시간 감소율 = 1 − ΣM2(변형)/ΣM2(기준). 95% CI는 시나리오 재표본 부트스트랩 2,000회이고, 추첨 오차만 반영한다.
  - 등급별 공백 가구 비율 = Σ공백 가구/Σ등록 가구.
- **코드.** `app/src/lib/sim/e5.ts`, `app/scripts/sweep.ts`(E5 분기), `app/scripts/e5-analyze.ts`(채점). sha256은 `prereg/e5.json`에 있다.

## 1. 예측 (E5 실행 전, 예비 실행 포함 E5 출력 0줄인 상태에서 커밋)

| # | 예측 | 판정 규칙 |
|---|---|---|
| 6.1 | AI 판독은 판독 없음보다 공백을 줄인다 | `AI@RULE` 대 `NOAI@RULE` 감소율 95% CI 하한 > 0 |
| 6.2 | 그 감소 폭은 3% 이상 | 위 감소율 점추정 ≥ 0.03 |
| 6.3 | AI 판독은 판독이 늘 맞을 때 얻는 이득의 절반 이상을 얻는다 | ΣM2(NOAI) − ΣM2(AI) ≥ 0.5 × (ΣM2(NOAI) − ΣM2(PERF)) |
| 6.4 | 실측 판독 오류를 넣어도 도구는 현행보다 10% 넘게 줄인다 | `AI@RULE` 대 `AI@KR_BASELINE` 감소율 95% CI 하한 > 0.10 |
| 6.5 | 판독이 없어도 도구는 현행보다 낫다 | `NOAI@RULE` 대 `AI@KR_BASELINE` 감소율 95% CI 하한 > 0 |
| 6.6 | 같은 보급량이면 기록 기반 표적 배치가 무작위 배치보다 공백을 더 줄인다 | `AI@RULE+P7T` 대 `AI@RULE+P7` 감소율 95% CI 하한 > 0 |
| 6.7 | 표적 배치는 1시간급 인공호흡기 가구의 공백 비율을 무작위 배치보다 낮춘다 | VENT_1H 공백 가구 비율 P7T < P7 |
| 6.8 | 표적 배치는 배터리 없는 산소발생기 가구의 공백 비율도 무작위 배치보다 낮춘다 | O2_STAT 공백 가구 비율 P7T < P7 |

## 2. 사용 규칙(결과 보기 전 고정)

- 보고서·랜딩에는 6.1(AI 기여 감소율)과 6.6(표적 대 무작위 감소율)만 싣는다. 맞든 틀리든 값을 그대로 싣고, 틀린 예측은 /lab에 공개한다.
- 6.1이 틀리면(CI 하한 ≤ 0) 보고서의 AI 기여 문장은 「모의에서 판독 기여가 확인되지 않음」으로 쓴다.
