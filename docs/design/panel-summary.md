## 2. 승자 선정 이유

evidence는 셋 중 원안 충실도와 준법에서 치명 위반이 없는 유일한 시안이다. 판정 근거는 다음과 같다.

**원안 충실도와 준법**
- 119 화면이 3필드다.
- 대기는 확정 통보가 있을 때만 허용한다.
- 여유는 범위로만 표시한다.
- least-slack 순서를 쓴다.

**측정 설계**
- 미등록 가구를 PlannerView와 WorldTruth로 분리했다.
- 표지에 Wilson CI를 붙이고 BORDERLINE 등급을 둔다.
- C2는 전부-null 기준선, 비자명 탐침 주 지표, 오라클 간 천장을 갖췄다.
- C3에 같은 비용 조건 검증기가 있다.

**형제 코드 결함 발견**
- 형제 `budget.ts`의 월 단위 키가 리셋되는 결함을 실제 코드로 짚었다.

**약점**: 범위가 과대하고 투표자용 화면이 늦게 나온다. 심사위원들은 다시 쓰기가 아니라 절단으로 고치라고 권고했다.

## 4. 이식한 아이디어

**mvp에서**
- D6 MVP 관문 G1과 실패 시 절단 계획
- materialize 시나리오를 오라클 입력으로 사용(PRNG 일치 불필요)
- C2·C3 공개 엔드포인트 0(공개 비용 면은 C1뿐)
- 엔진 숫자 리터럴 금지와 장부 키 강제
- 유사명 미끼 라벨, 무플래그 오매칭 상한 2%
- 하한 분해식의 회색 줄 표시(마치다 양식)
- `/ops`의 '정전→순위 지연 ms' 실측
- 14% 확인 실패 시 사건형 대체 문장

**judge에서**
- 감마 1,001점 역누적분포 표를 scipy로 만들어 봉인하고 TS·Python이 공유(보고서의 감마 선택과 일치)
- 정수 초 양자화(은행가 반올림 회피)
- TYPHOON_STRONG 구간선형 CDF, APT_PARTS의 assumed 표기
- σ_e > 0.75면 HOLD 금지(후회 최소 규칙), `UNSERVED_VISIBLE` 레인
- `ClosingCard`와 `evidence.json` 자동 주입('측정 전' 표시)
- OG 이미지, LCP·JS 예산
- 화면×심사항목 대응표, `/judge` 3분 경로(정적)
- 3분 영상 초 단위 콘티
- 3명 중 2명 10초 시험
- C2 3회 실행 다수결과 자기일관성
- 경계값 탐침(1,499/1,500/1,501MW 등)
- MoSCoW 절단 순서

**evidence에서 유지한 뼈대**
- PlannerView/WorldTruth 분리(ESLint 경계)
- Wilson CI와 BORDERLINE 등급
- C2 비자명 탐침, 전부 null 기준선, 지어낸 보호 규칙 비율, 오라클 간 천장 85%
- C1 personalInfoVisible, 퍼지 매칭은 운영자 후보 제시에만 사용
- C3 같은 비용 조건 검증기, 기준선 4종
- `R_L` 절제
- OTS 한계 명시
- geolocation 트랩과 이미지 비저장 E2E

## 5. 종합자가 새로 정한 것

- **KR 기준선 이중 구현 동등성 시험.** D7에는 시뮬레이터 내장 경로, D8에는 DSL 경로로 구현하고 두 경로의 스윕 해시가 같아야 한다. DSL 인터프리터를 검증하는 시험이다.
- **C2 보류 문서를 4건으로 늘림.** 약관 제47조, 이나기, PG&E, WG+E이고, 모두 비자명 규칙이 있는 문서로 골랐다.
- **C3 실행 순서.** C2 보류 측정 뒤에만 실행해 보류 문서의 오라클 DSL이 섞이지 않게 했다.
- **E3 두 바탕.** 보완안을 KR_BASELINE 위와 RULE 위 두 가지로 평가한다.
- **예산 재계산.** 실제 단가 $2/$10 기준으로 계획 $27.3, 예비 $22.7이다.
